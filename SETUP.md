# Luxury Editorial Photography Studio — Setup Guide

Welcome to the **Luxury Editorial Photography Studio (Edition 2)** setup guide. This platform features a curated React 18 + Vite frontend with GSAP ScrollTrigger animations.

- **GitHub Repository**: [https://github.com/JeevananthanV/photo_studio_2](https://github.com/JeevananthanV/photo_studio_2)
- **Author**: Jeevananthan V

---

## 📋 System Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Git**: v2.30.0 or higher

---

## 📥 1. Clone the Repository

```bash
git clone https://github.com/JeevananthanV/photo_studio_2.git
cd photo_studio_2
```

---

## 📦 2. Install Dependencies & Run

```bash
cd photo-studio
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🏗️ 3. Production Build

```bash
cd photo-studio
npm run build
npm run preview
```
Output is compiled into `photo-studio/dist/`.

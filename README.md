## 🎨 Visual Identity & Design System

The platform is designed around a bespoke editorial aesthetic:

- **Typography**:
  - Headings: `Playfair Display` serif for timeless sophistication.
  - Body & UI: `Inter` sans-serif for clean legibility.
- **Color System**:
  - **Base** (`#FAF8F4`): Warm paper background.
  - **Surface** (`#F2ECE3`): Elegant contrast bands.
  - **Ink** (`#1C1917`): Deep off-black headings.
  - **Accent** (`#B08544`): Antique Gold call-to-actions.
  - **Secondary** (`#7A6A55`): Muted bronze metadata tags.

## 🚀 Getting Started

### Clone

```bash
git clone https://github.com/JeevananthanV/photo_studio_2.git
cd photo_studio_2
```

### Installation & Run

```bash
cd photo-studio
npm install
npm run dev
```

Open `http://localhost:5173` to explore the editorial experience.
